مشروع Nouifla Studio - النسخة الأولية

محتويات المشروع:
- index.html: واجهة التطبيق باللغة العربية.
- manifest.webmanifest و sw.js: أساس تثبيت التطبيق كـ PWA والعمل دون اتصال بعد أول تحميل.
- icons/icon.svg: أيقونة المشروع.
- capacitor.config.json: إعداد أولي لتغليف المشروع كتطبيق Android باستعمال Capacitor.

طريقة التجربة:
1) فك الضغط عن Nouifla-Studio.zip.
2) ارفع محتويات المجلد إلى مستودع GitHub (وليس ملف ZIP وحده).
3) من GitHub افتح Settings ثم Pages، واختر Deploy from a branch، ثم main و /root، واضغط Save.
4) بعد نشر الموقع افتح الرابط على الهاتف. من قائمة المتصفح اختر Add to Home screen / إضافة إلى الشاشة الرئيسية.

مهم:
هذه نسخة أولية وليست محرر فيديو احترافياً مكتملاً مثل CapCut أو InShot.
الاستيراد والمعاينة والمسار الزمني تجريبية، والتصدير الحالي WebM لصورة ثابتة فقط.
لا يوجد APK جاهز داخل هذا الملف. إنشاء APK يحتاج بناء Android باستعمال Capacitor و Android Studio أو بيئة بناء مناسبة.
لا ترفع مفاتيح أو كلمات مرور إلى GitHub.
